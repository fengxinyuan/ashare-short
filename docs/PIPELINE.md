# 计算链路

本文说明舆情、板块、选股与买卖点如何计算。命令和开关见 [使用指南](USAGE.md)，
来源、量纲和历史测量见 [数据源说明](DATA_SOURCES.md)，任务与存储职责见 [系统架构](ARCHITECTURE.md)。

```text
行业与概念定义 ──→ 成分股日线 ──→ 板块动量
新闻与公告 ──→ 去重、时效、归因 ──→ 板块舆情与风险
龙虎榜 ──→ 成分股净买额汇总 ──→ 板块资金旁证
                         ↓
大盘情绪与仓位约束 ──→ 行业/概念分别排序
                         ↓
可交易性、公告、业绩筛选 ──→ 打法门槛 ──→ 个股粗排与精排
                         ↓
日线、分时与盘口事实 ──→ 候选价位 ──→ 规则默认 / 可选模型裁决
                         ↓
事实包、简报与计划归档 ──→ 盘中确认与告警 ──→ 盘后复盘与兑现核对
```

同花顺行业指数、价格轮动和成交额迁移作为并列读数，不混入成分股聚合评分。
各层保留实际来源、数据时点、覆盖率与降级原因。

## 舆情采集与归因

### 缓存与语料库

`NewsCache` 按交易日和来源复用请求，默认 TTL 为一小时；`NewsStore` 跨日保存原文和观察记录。
语料库保存 `first_seen_at / last_seen_at / seen_count`，区分首次出现与重复传播。
两者分别解决重复取数和证据回放，不能互相替代。

| 来源 | 主要内容 |
|---|---|
| AkShare 商业快讯 | 财联社、东财、同花顺、新浪快讯与财经早餐 |
| 新闻联播、沪深公告 | 政策与公司披露；公告自带代码和类型 |
| 华尔街见闻 | 宏观数据发布、海外流动性与跨市场事件 |
| 国内官方栏目 | 国务院、人民银行、证监会发布 |
| 海外官方 RSS | 美联储、BEA、人口普查局、EIA、BLS 等公开发布 |
| 显式提供的社媒材料 | 主题线索，保留低可信标识 |

华尔街见闻快讯按时间窗翻页：当日从实际采集时刻回溯 72 小时，周一早晨也覆盖周五早盘；
历史日期以该日结束为回溯锚点。达到页数上限、途中失败或游标重复时保留已采到的内容，
报告分页不完整，并且不写入完整缓存。单路不可用不阻断其他来源；HTTP 成功但无有效内容
仍需报告覆盖情况。

用于情绪打分的文档按发布时间作 12 小时半衰期折减，超过 72 小时剔除。
带时区的发布时间先换算为北京时间，再计算时效；跨源同标题合并并保留最早发布时间。
无法解析时间的记录不作时间折减，但计数并说明。

### 标签与通读

`news/llm_classifier.py` 只输出板块、方向、事件类型和传导机制；分值由固定规则映射。
标签通过标题前缀与原文对齐，板块、方向和事件类型校验合法值。无法说明传导机制的归因弃权；
批量对齐失败则退回关键词词典，未知事件类型置空，不抹掉其他有效标签。

`news/daily_read.py` 组织跨条目的“触发 → 机制 → 品种 → 方向”、主线与风险：

- 每条结论回抄对应标题前缀，无法核对则丢弃。
- 输出数字通过事实校验，不能从标题推造高开幅度或收益概率。
- 取样按海外、地缘、大宗、政策、宏观与 A 股等分节配额分配，防止最新盘面快讯占满输入。
- 通读结果只解释事实，不改变板块分和候选排序。

模型分析缓存绑定实际输入、提示词与模型配置。更换新闻、持仓或板块清单后，按新的输入
重新分析；同输入仍可复用。分类只有完整结果才写缓存，部分失败可在下一次重试；
通读缓存命中后仍须通过原文引用和数字校验。

采集、板块归因与通读可以使用不同条数上限，但共用原文。是否调用模型按
[模型开关](USAGE.md#模型开关) 配置；关键词维护分别在 `news/lexicon.py` 与 `sectors/keywords.py`。
词典权重和标签分值均为规则先验，不是概率。

## 板块定义、动量与研究读数

### 分类与覆盖

盘前、调度与盘中通过 `static_taxonomies()` 使用同花顺行业和概念。行业只有一个层级，
标识为 `THS_INDUSTRY`；概念以 `CONCEPT` 单独排名和分配名额，数量随上游变化。
概念排除交易资格等非主题标签，默认只设规模下限，不重复计入全市场宽度。

分类来自第三方托管的同花顺静态快照，行业取原始数组的第二项，与当前行业指数名称对应。
保留板块与成分股的映射供选股、宽度统计和持仓归属使用，画像只输出 `industry` 与 `concepts`。
旧缓存可转换读取；没有可用行业分类时报告 `SectorTaxonomyError`，不切换到另一套分类。
新行业排名与旧 `SW1` 等历史记录分开积累，旧记录保留，不合并计算延续性。

`SectorMomentum` 从成分股日线计算中位涨幅、上涨占比、量比、站上 MA20 占比、
中期收益与回撤。中心值使用中位数，降低少量极端涨幅对排名的影响。
覆盖不足的板块标记 `trusted=False`，可展示但不入选，不能用默认中性分代替缺失。

### 行业指数与轮动

同花顺行业指数保留自己的分类与权重口径，提供收盘日内位置、距近期高点及历史序列。
它与成分股等权聚合并列，不能直接强行映射后相加。

价格轮动基于共同交易日的收益和排名，比较不重叠窗口：

| 字段 | 含义 |
|---|---|
| `switch_correlation` | 前一长窗口与近期短窗口的横截面秩相关，观察月度趋势延续或反转 |
| `adjacent_correlation` | 相邻等长窗口的秩相关，观察近期高低切换 |
| `rank_change` | 与相邻窗口一致的排名变化，定位具体板块 |

长窗口包含近期窗口会产生机械的正相关，不能用于判断轮动。两种不重叠窗口的读数可能异号，
代表不同时间尺度。`sectors/panel.py` 统一日期面板，缺失交易日不按位置硬配对。

### 成交额迁移

成交额为双边交易量，不等于净流入。`sectors/turnover.py` 同时报告板块占比变化、
全场总量变化与绝对成交额变化，避免把普遍缩量误读成逐板块流出。

| 成交额占比 | 价格 | 描述 |
|---|---|---|
| 上升 | 上涨 | 放量上涨 |
| 上升 | 下跌 | 放量下跌 |
| 下降 | 上涨 | 缩量上涨 |
| 下降 | 下跌 | 缩量下跌 |

这些组合描述量价状态，不能仅凭成交额占比推断买卖方向或真实资金迁移。
绝对额榜补充占比榜，防止全场缩量时漏掉成交额明显下降的板块。

主题簇、跷跷板、外盘映射与历史基准率读取相同历史材料，并保留各自的样本覆盖和稳定性检查。
盘前把隔夜外盘异动按 `sectors/overseas_link.py` 的映射表挂到候选行：利空进风险栏，利多进理由栏，
不改板块分与候选排序；没配海外快照源时只留一句说明。
固定板块价格基线用于研究信号，不代表整条选股与执行链路的收益。

板块价格基线统一交易日格式，以代码区分板块。低覆盖或无有效价格的已知日期仍保留在
日期轴上；缺失窗口跳过，不用后面的日期补成 T+1。1/3/5 日各自使用已完成的窗口。
`holdout` 按共同信号日期轴的最后 30% 划分，`common_holdout` 再对齐各方法都有结果的日期；
后者适合横向比较。入选和基准均为行业中位价格变化，`win_rate` 是跑赢该基准的比例，
并非交易盈利胜率；不含执行、费用与滑点，当前行业样本仍可能带来幸存者偏差。

## 板块排序与仓位约束

板块评分以基准 50 叠加动量、舆情和资金读数。舆情有幅度上限，并按样本量折权，
避免少量快讯给出与大量证据相同的权重；板块舆情和个股舆情的上限分别为 ±12、±6 原始分。

仓位建议以可信板块的覆盖加权宽度为锚，基准为 `0.15 + 宽度 × 0.75`，上限 0.80。
缺少可信宽度时使用明确标注的中性基准；普涨过热时连续折减，宏观舆情只作有限调整。
情绪周期还会限制可用打法与仓位，最终保存完整的约束过程。手工仓位与系统建议分别展示，
不是对账户资金的自动操作。

情绪读数缺失、NaN、越界比例或非整数家数均按未知处理，不补成零；完整读数才能确认
启动、发酵等周期。已验证的跌停恐慌等冰点条件仍可独立停止新开仓，其他字段缺失不覆盖
这类已知风险。真实的零家涨停与未取得涨停家数分别处理。

涨停/炸板池补充封板意愿：炸板率为 `炸板 / (涨停 + 炸板)`，连板高度使用 `lbc`，
不能用”N 天 M 板”的 `zttj` 替代。响应的 `qdate` 是服务端所知的最新交易日，只在请求
日期晚于它时（周末、盘前问”今天”）用来标注回退；情绪周期只用**上一个已收盘**交易日
的池子，开盘后跑批会跳过今天还在形成中的池子并在 notes 里说明。

全市场扫描是实时快照：09:15 到收盘之间取到的成交额是半截交易日的，那时可交易性只按
流通市值筛，成交额门槛停用并写进 notes。

宽基指数用于对照成分股宽度。只有日期可比时才判断“宽度较强但指数较弱”等背离，
日期未知或不一致时只报告各自事实。该读数不直接修改评分与仓位。

## 个股筛选与排序

### 风险筛选

顺序为可交易性、致命公告、业绩否决；筛选失败直接排除，后续加分不能抵消。
主链路不再按 ST 名称或代码段默认过滤，独立策略命令的显式选项见使用指南。

可交易性默认要求流通市值至少 20 亿、日成交额至少 0.8 亿，阈值为规则先验。
缺少行情时放行并记录“未完成可交易性过滤”，不能把缺失视为已确认风险。

盘前公告按自然日回退最多五天，使用最近有公告的日期并记录时点；始终取不到时说明风险筛选缺失。
新闻联播同样回退最近有内容的一期。业绩按净利润指标、报告期和方向解释，
亏损与预减参与否决，正面信息不能绕过其他风险门槛。

### 先过打法门槛，再评分

`strategy/regime.py` 决定当日允许的打法，`strategy/playbook.py` 决定个股条件，两者取交集。
当前链路包含多种打法，低吸不是唯一或所有时段的默认打法。

| 个股趋势 | 可检验的打法 |
|---|---|
| 上升趋势 | 突破、回踩 |
| 反弹 | 回踩 |
| 震荡 | 区间下沿 |
| 下跌趋势 | 有明确触发的超跌反转 |

回踩把缩量作为门槛，不能用其他因子加分补回；突破检查位置和持续量能，过量同样可能失效。
超跌反转要求触发证据，仅跌得多不成立。生产中的量能反转条件是当日涨幅为正且达到量能门槛，
严格的前阴实体反包尚未接入，术语边界见 [形态知识库](KNOWLEDGE_VOLUME_PRICE.md#32-反包)。

`signals/dipbuy.py` 按自身 ATR% 归一化回调深度，档位边界为 0.8/2.0/4.0 个日波幅。
真实波幅包含跳空，避免一字板的日内区间为零时低估波动。止损距离同样使用 ATR 尺度，
过近与过远的结构不能因机械盈亏比获得高分。回调阶段的缩量与启动阶段的放量分别解释。

### 粗排、精排与上下文

日线技术面、威科夫和量价画像先粗排，再为有限的入围标的获取个股新闻并精排。
当前候选扩展为每板块配额的三倍、全局封顶 40 只；被截断的覆盖单独报告。
两轮复用已计算的日线读数，避免重复取数与重复归一化。

`StockFactorContext` 保留二级因子的读数和分项：

| 因子 | 处理方式 |
|---|---|
| 板块关系 | 仅使用覆盖可信的板块评分、宽度和资金强弱 |
| 相对强弱 | 个股收益与所属板块同期收益比较 |
| 资金旁证 | 相对候选与成交额归一，不直接比较不同标的的绝对金额 |
| 持续量价 | 区分放量上涨、放量下跌、连续扩量与高位滞涨 |
| 业绩、政策与事件 | 作为有限的二级排序依据，不替代价格结构与风险筛选 |

上下文加分有总上限，下跌趋势的正向贡献进一步受限。结果和台账保存 `score_components`
与 `factor_context`，缺失信息按未知处理。

个股新闻在打分前经过 `news/relevance.py`：标题需关联公司，允许公司或控股股东自指；
证券简称未知时放行并保留限制。按代码关联的公告不走此闸门。行业综述与榜单不能把别家公司的
利好利空记到本标的。通读可使用更宽的历史材料，与短期情绪打分的时间窗口不同。

## 候选价位与模型裁决

L1 汇集日线、分时与盘口事实，L2 生成带 `basis`、`evidence` 和默认排序的候选，
L3 在显式开启时从已有候选键中选择或弃权。关闭或失败时使用规则默认。

| 候选来源 | 所需数据 |
|---|---|
| VWAP、当日高低点 | 有效的当日分钟线 |
| 五档买卖盘墙 | 当前盘口及可解释的挂单厚度 |
| 日线支撑压力、区间边界与缺口 | 有效且价格尺度对齐的历史日线 |
| ATR 回调位置 | 可用的波动与回调画像 |
| 涨跌停价 | 适配器返回的真实价格，不用固定百分比猜测 |

额外候选受距离护栏约束，规则默认价位始终保留在候选集合内。买入触发可以是高于现价的
条件价。现价上方没有历史参照时不给虚构目标，并说明相应位置与跟随条件。

挂单墙同时考虑绝对金额、占本方挂单的比例及相对当日成交额；缺少成交额时按已有门槛解释。
封死涨跌停时委比退化为离散状态，不能当成连续强弱分数。五档用于候选、动作可执行性与旁证，
不直接成为选股分数。

执行风险要求止损低于整个买入区间、最近目标高于买入价，且所有价位有限并为正。
计划按区间上沿计算盈亏比；监控在此基础上再按现价检查，避免追价后风险扩大仍沿用旧比值。
问答卡片会从价位重算，裁决及监控锁定价位也会刷新风险提示。1.5 的门槛比较使用未舍入值，
不让 1.499 因显示为 1.50 而放行；该比值尚未扣除费用与滑点。

盘前的成交逐笔在最终候选确定后补充，只作旁证，不改这次入选排序。
数据为当日或最近交易日的成交切片，主动方向属于行情方推断；翻页和字段口径见数据源说明。

情景按“强势延续、均价震荡、转弱回落”给出触发价位与失效条件，不输出未经验证的未来概率。
模型输出的数字、措辞、立场和候选键校验统一见 [输出闸门](ARCHITECTURE.md#输出闸门)。

## 持仓风险与输出交接

盘中监控覆盖止损、目标、结构破坏、时间止损与浮盈回吐，并先检查数据时效。
手工 `plan_stop / plan_target` 优先于系统候选，不受等待开盘结构形成的限制，告警标明“你设定的”。
用户已指定目标时，不再把系统目标阶梯对应的盈亏比混在一起展示。

浮盈回吐同时要求回吐至少一个日均真实波幅、且达到峰值浮盈的一半。
峰值从建仓日后的历史高点播种，盘中用当日最高更新；成本、ATR、峰值未知时不判断。
未登记建仓日时不拿整段历史最高冒充持仓峰值。日线无法区分建仓当天买入前后的高点，
这项限制随读数保留。阈值是规则量级，没有收益拟合保证。

简报由模板生成；可选模型改写通过校验后使用，失败回退。纪律文本由程序追加，
盘中紧急告警使用模板。事实、计划、监控事件和盘后复盘按实际时点归档，兑现核对要求完整窗口。
执行核对分别保存价格触及、模拟成交与是否平仓：突破按上穿触发，回踩遵守区间下沿，
弃权和无效计划不建仓。价格锚与执行日期分开，分时参考价用保存的同日开盘价对齐复权尺度，
旧参考日不能让核对窗口提前到建议发出前。缺少必要开盘价时留待补齐后核对。
T+1、期末封板及无法确认离场的记录不进入已实现收益统计；同日对照还需匹配模拟版本。
评分、筛选和裁决比较匹配来源与策略版本，按共同交易日等权，不以总体中位数之差替代配对结果。
评分分项在同日可比组内分组，保留同分；次日和已实现收益分别计算有效覆盖，判读注明所用口径。
覆盖不足的极端成交不能决定分项方向；分组差值用于人工复查，不证明单项因果，也不自动调整权重。
固定费用情景和成交日归集曲线用于研究，不含滑点、最低佣金和完整的资金占用模型。
