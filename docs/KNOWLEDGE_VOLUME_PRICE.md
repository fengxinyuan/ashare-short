# 量价与形态知识库

本页整理量价白皮书、尾盘选股口述流程和常见 K 线术语，并标明当前实现范围。
白皮书来源为 `股票量价——白皮书(1).pptx`（46 页，标注更新于 2026-07-23），
原件不纳入版本库。以下阈值与形态解释属于经验规则，未经本系统回测标定。

计算链路见 [PIPELINE.md](PIPELINE.md)，数据量纲见 [DATA_SOURCES.md](DATA_SOURCES.md)。

## 1. 量价口径

### 1.1 成交量、金额、换手率与量比

| 指标 | 口径 | 使用范围 |
|---|---|---|
| 成交股数 | 成交量，适配器统一为股 | 同一标的纵向比较 |
| 成交金额 | 成交量对应金额，统一为元 | 交易活跃度；不能直接推断净流入 |
| 换手率 | 成交量 / 流通股本 | 跨标的比较仍需考虑流通盘与限售差异 |
| `volume_ratio_20d` | 当日量 / 前 20 日均量 | 日线量能 |
| `IntradaySnapshot.volume_ratio` | 当日累计量 / 基线日相同交易分钟数的累计量 | 盘中量能 |
| `vol_ratio_1d` | 当日量 / 前一日量 | 倍量与三倍量 |

盘中量比按相同分钟进度比较，避免用全天均量线性折算时忽略开盘、尾盘的成交集中。
`turnover_rate` 与 `turnover_rate_20d` 可比较当前换手和自身常态，不能用日线量比
替代盘中量比。

### 1.2 量价八阶律

白皮书 slides 8–26 的描述需结合趋势与位置，不能直接作为买卖信号。

| 形态 | 原始解释 | 当前读数与限制 |
|---|---|---|
| 价平量增 | 低位转强或上升途中整理 | `quadrant=横盘` 配合 `vol_ratio_20d` |
| 价涨量增 | 多头进攻 | `QUADRANT_UP_EXPAND`；突破仍需通过打法门槛 |
| 价涨量平 | 上涨延续 | `QUADRANT_UP_FLAT` |
| 价涨量减 | 惜售或推动力衰减 | `QUADRANT_UP_CONTRACT`；创新高时另查顶背离 |
| 价平量减 | 高位警戒 | 缩量横盘本身不能确认出货，需结合位置 |
| 价跌量减 | 回调或阴跌 | `QUADRANT_DOWN_CONTRACT`；趋势未破时可能符合回踩 |
| 价跌量平 | 弱势延续 | `QUADRANT_DOWN_FLAT` |
| 价跌量增 | 破位或低位剧烈换手 | `breakdown_on_volume` 覆盖放量跌破均线，不能据此确认吸筹 |

缩量上涨与顶背离、缩量下跌与回踩分别由位置和趋势区分。
策略层使用 `trend_state`、`range_position_60d` 与 `pullback_band` 检验打法；
突破的顶背离否决、回踩的缩量门槛不能由其他加分抵消。

### 1.3 涨跌停与封板质量

涨停无量可能来自卖盘缺失，跌停无量可能来自买盘缺失，常规量价解释在此不适用。
封死涨跌停时委比退化，`OrderBookReading.is_degenerate` 标识这一状态。
挂单可撤，单次封单厚度不能证明持续承接或未来延续。

`LimitStock` 已解析首封时间 `first_seal`、封单金额 `seal_fund`、炸板次数 `blowups`
和连板数 `streak`；快照提供早封占比、封单金额中位数、换手中位数及行业分布。
这些是池子快照，尚无连续封单变化率与完整撤单时序。`strong_count` 的涨幅近似口径
与真实涨停池名单仍分别使用。

### 1.4 成交量的解释边界

白皮书 slides 7、32 提醒成交量可能受对敲影响。价格结构仍是判断基础，
放量本身不能证明主力身份或构成买入理由。
`up_down_vol_ratio` 只是上涨日成交量与下跌日成交量之比，不等于逐笔主动买卖额。

### 1.5 温和放量与量堆

量堆通常指低迷后连续温和放量，并在回调中维持结构。
现有 `vol_trend_5d`、`expanding`、`dry_up` 描述量能变化；
尚未实现山形量堆的峰形约束与趋势线确认。

### 1.6 突破位置

白皮书 slides 38–40 提醒高位盘整、除权后盘整、下跌途中的平台突破可能失效。
当前突破规则要求 60 日分位不低于 `BREAKOUT_POSITION_MIN`，并检查量能上限与顶背离；
高分位与透支风险的取舍尚需验证。下跌趋势只检验反转打法，不检验普通突破。

### 1.7 除权与送转

系统没有专门的送转事件策略。前复权日线会消除除权缺口，不能仅据此判断近期是否除权。
历史结构价与分时实际价的尺度对齐见 [时间与价格](DATA_SOURCES.md#时间与价格)。

### 1.8 结构与纪律

白皮书 slide 45 的结构要求与当前实现对应如下：

| 原始要求 | 当前覆盖 |
|---|---|
| 破位退出 | 已有均线与持仓结构检查；未实现全部趋势线、颈线组合 |
| 高位巨量警戒 | `climax`、`climax_stall`；多日长阴确认尚未接入策略 |
| 筑底时间影响后续空间 | 尚无筑底时长与目标空间的可靠映射 |
| 上升趋势缩量回踩均线 | `PULLBACK` 检查趋势、回调与缩量；实际使用 MA20，非原文全部均线 |

## 2. 尾盘选股（一夜持股法）

### 2.1 时间窗口

尾盘买入减少当日剩余持有时间，但仍承担隔夜跳空与 T+1 限制。
本节记录原始方法，不代表 `strategy-screen` 已执行完整的盘中确认流程。

### 2.2 原始筛选条件与实现范围

| 条件 | 原始经验范围 | 当前支持 |
|---|---|---|
| 大盘环境 | 避开放量下跌与退潮 | 情绪闸门提供炸板率、连板高度等约束 |
| 当日涨幅 | 3%–5% | 已有日线与实时涨跌读数，阈值需按打法验证 |
| 盘中量比 | 大于 1 | `IntradaySnapshot.volume_ratio` |
| 换手率 | 5%–10% | 已有当日与历史换手；统一范围可能误排活跃题材股 |
| 流通市值 | 50–200 亿 | `LiquidityScreen` 提供下限筛选，未实现本方法的完整区间 |
| 形态与分时 | 温和放量、均线排列、站稳 VWAP、强于基准 | 有量能、均线、VWAP 与相对强度读数，尚未合为完整判据链 |

盘中分析必须检查 `is_current_session` 与数据时效。策略筛选参数和实际数据截止日
见 [参数化策略筛选](USAGE.md#参数化策略筛选)。

### 2.3 尾盘量价

`closing_drive_pct` 表示尾盘 30 分钟涨幅，`closing_volume_ratio` 将同一窗口成交量
与基线日相同分钟区间比较。两者可区分放量拉升和缩量拉升，但不能据此确认吸筹、
洗盘或次日高开概率。

分母不用当日全天分钟均量，避免日内 U 形成交分布使尾盘量比系统性偏高。

### 2.4 原始风险设定

口述方法给出的止盈 2%–5%、止损 1.5%–3%、次日退出、单票不超过 20% 和总隔夜
仓位不超过 50% 都是经验范围，未作为统一默认规则。
跳空穿越止损时无法保证按止损价成交；兑现核对的执行口径见
[台账与复盘](ARCHITECTURE.md#台账与复盘)。

## 3. K 线形态词典

### 3.1 倍量与三倍量

倍量为当日成交量至少为前一日的 2 倍，三倍量为至少 3 倍。
对应 `vol_ratio_1d`、`DOUBLE_VOLUME` 与 `TRIPLE_VOLUME`，不能用对 20 日均量的
比值代替；连续放量时两种比值可能给出不同标签。

### 3.2 反包

通常定义为阳线收盘不低于前一根阴线开盘；强反包进一步要求超过其最高价。
当前 `strategy/playbook.py:_check_reversal` 的“放量反包”标签只要求当日涨幅为正且
`volume_contraction >= REVERSAL_VOLUME_MIN`，没有比较前阴实体或最高价。
严格反包几何尚未接入生产策略。

### 3.3 涨停、倍量阴与反包序列

原始序列为涨停或大阳、倍量阴、缩量调整、放量反包倍量阴。
通常还要求倍量阴实体不过大，调整期不破关键低点。
现有日环比量能与涨停读数可作输入，但实体相对位置、逐日缩量和完整序列尚未接入策略。

### 3.4 三阴包阳

该词有相反用法，使用前需明确条件：

- 看空：三根阴线累计跌破此前阳线开盘价。
- 看多的“三阴不破一阳”：大阳后连续调整且缩量，始终未破指定开盘价或低点。

两者不能共用同一触发标签，当前未作为完整生产策略。

### 3.5 品字形

常见用法包括三根 K 线组合、三次冲击压力区和分时三段推升，尚无统一定义。
现有支撑压力位不等于三次触及的时序结构；系统未实现专门的品字形策略。

### 3.6 其他形态

| 形态 | 当前覆盖 |
|---|---|
| N 字结构 | 回踩打法覆盖部分条件，未单独验证完整 N 字序列 |
| 龙回头 | 有回踩与龙头研究读数，未合成独立触发链 |
| 一阳穿多线 | 有均线读数，未实现独立组合策略 |
| 平台突破 | 有突破门槛，平台时长与完整形态确认仍有限 |
| 地量后首阳 | `_check_reversal` 的 `dry_up_turn` |
| 天量滞涨 | `climax_stall` |

## 4. 实现边界

基础特征可用不代表组合形态已经成为自动信号。新增打法或修改阈值应单独验证，
不能用术语相似代替判据一致。模块职责见 [系统架构](ARCHITECTURE.md#筛选与监控)，
验证入口见 [测试指南](TESTING.md)。
