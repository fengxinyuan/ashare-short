# 数据源与校验

本文维护接入方式、字段口径、缓存和接口边界。安装步骤见 [项目首页](../README.md)，
日常操作见 [使用指南](USAGE.md)，运行与状态约束见 [系统架构](ARCHITECTURE.md)。
本文的接口测量来自 2026 年 8–9 月；套餐价格、权限、成功率和延迟均为当时记录，
当前可用性需重新诊断，离线测试不重测外部接口。

## 配置

`tickflow` 可选依赖提供行情 SDK，`akshare` 提供新闻、分钟线、业绩、龙虎榜席位与交易日历接口。
CLI 与 MCP 启动时依次查找 `$ASHARE_DS_ENV_FILE`、当前目录、仓库根和 `$ASHARE_DS_HOME`；
各目录内按 `.env.tickflow`、`.env.feishu`、`.env` 的顺序读取。
已有环境变量优先，包括显式设置的空字符串；空值可用于禁用文件中的密钥。
同名配置先读到的生效。配置文件支持整行注释，
不要在密钥后写行内注释。适配器自身只读取环境变量。

| 配置 | 用途 |
|---|---|
| `TICKFLOW_API_KEY` | 未设置时使用免费客户端；有密钥时使用付费客户端，能力仍取决于账号权限 |
| `TICKFLOW_BASE_URL` | 可选的接口地址覆盖 |
| `TICKFLOW_RATE_LIMIT` | 免费客户端的每 60 秒调用上限，默认 55 |
| `DASHSCOPE_API_KEY`、`DEEPSEEK_API_KEY`、`GLM_API_KEY`、`KIMI_API_KEY` | 对应模型提供方；各命令是否调用模型见 [模型开关](USAGE.md#模型开关) |
| `FEISHU_WEBHOOK_URL`、`FEISHU_SECRET` | 可选的飞书 webhook 与签名；应用模式配置见 `.env.feishu.example` |
| `ASHARE_DS_HOME` | 状态目录，默认 `~/.ashare-ds/` |
| `ASHARE_DS_ENV_FILE` | 优先读取的配置文件路径 |

`ashare-ds state` 显示实际加载的配置文件和 TickFlow 模式，适合检查当前进程是否取得配置。
AkShare 接口可能随版本变化；历史测量使用 `akshare 1.18.81`，字段变化时需同时核对安装版本。

## 运行链路使用的数据源

| 数据 | 来源与入口 | 用途及边界 |
|---|---|---|
| 个股日线 | `TickFlowAdapter` | 默认比例前复权；优先批量获取，网络失败可回退本地日线 |
| 分钟线 | `build_intraday_adapter` | 根据 `supports_intraday` 选择 TickFlow，否则使用新浪；周期为 1/5/15/30/60 分钟 |
| 实时快照与五档 | `SnapshotAdapter` | 默认腾讯，可选新浪；腾讯响应同时提供真实涨跌停价 |
| 全市场扫描 | `MarketScanAdapter`、`TickFlowMarketScanAdapter` | 免费使用新浪；付费时两路合并，主源整行优先、兜底填空，并输出跨源校验 |
| 行业与概念 | `ThsTaxonomySource` | 同花顺分类的第三方静态快照；行业只有一个层级，概念动态更新；盘前、盘中与选股共用口径 |
| 板块指数 | `ThsSectorIndexAdapter` | 同花顺行业指数与成分股聚合读数并列呈现，保存日线供轮动研究 |
| 涨停、炸板与强势股池 | `LimitPoolAdapter` | 东财 `push2ex`；`qdate` 是服务端所知的最新交易日，仅在请求日晚于它时按它回退；盘中跳过当日未定格的池子 |
| 新闻与公告 | `jobs/sources.py:default_news_source` | 商业快讯、华尔街见闻、国内官方栏目和海外官方 RSS；分别缓存与报告故障 |
| 业绩预告与快报 | `EarningsAdapter` | 净利润口径优先；亏损和预减可参与风险否决，缺失保留未知 |
| 龙虎榜与席位 | AkShare、`LhbSeatAdapter` | 盘后披露数据，不是盘中资金流；大市值标的未上榜属于正常缺失 |
| 当日成交明细 | `TencentDetailAdapter` | 腾讯 3 秒切片，B/S/M 方向为行情方推断 |
| 宽基与海外快照 | `BroadIndexAdapter`、`GlobalMarketAdapter` | 新浪；指数、ETF、期货和汇率保留各自时点与字段布局 |
| 指数历史 | `ThsSectorIndexAdapter`、`OverseasHistoryAdapter` | 多年日线供基准率与固定基线研究，不代表分钟级策略回测 |
| 交易日历 | `AkshareCalendarAdapter` | 只调用交易日历接口；刷新时校验年份覆盖并保留已有有效年份 |

行情请求成功、数据足够新和整条任务完整运行是三项独立检查。缺失或陈旧数据需要在产物中说明。

分类文件来自 `https://files.688798.xyz/ths/` 的 `industries.json` 与 `concepts.json`。
系统只保留行业数组第二项；2026-09-13 实测，与取得的 90 个同花顺行业指数名称对应。
这只验证了名称对应关系，尚未逐一核验官方成分。行业指数直接读取
`d.10jqka.com.cn`，成分股关系用于选股、上涨家数和涨停扩散统计，报告不展开全量名单。

## 字段口径

适配器在边界统一成交量为股、金额为元、收益率为小数；下游不再按数据源猜单位。

| 上游字段 | TickFlow | 新浪 | 腾讯 |
|---|---|---|---|
| 行情与分钟线 `volume` | 手，乘 100 | 股 | 手，乘 100 |
| 成交 `amount` | 元 | 元 | 万元，乘 10000 |
| 五档挂单量 | 按对应接口契约解析 | 股 | 手，乘 100 |
| 行情涨跌幅 | `ext.change_pct` 为小数 | 百分数，除以 100 | 按快照布局解析 |
| 流通市值 | 流通股本 × 现价，元 | `nmc` 为万元，乘 10000 | 不以缺失字段推测 |

腾讯五档只精确到手，零股差异不应解释为单位错误。`numeric.finite` 排除 NaN、Infinity、
布尔值和溢出；TickFlow 分钟线的 OHLC 保留四位小数，消除独立浮点运算造成的尾差。

跨源校验只报告，不改数、不替调用方选择来源。接近 100/10000 倍的差异提示单位问题，
同量纲下的小幅差异可能来自厂商归并边界。没有差异时也记录已完成比对。

### 时间与价格

时间先转换为北京时间，再比较请求日期、交易日和采样时点。缺失时间保持未知，
晚于采样时点的数据不能解释为零延迟。盘中监控发现数据陈旧或停止推进时挂起实时信号，
继续检测恢复。

| 序列 | 口径 | 使用要求 |
|---|---|---|
| TickFlow 日线 | 默认 `forward` 比例前复权 | 用于趋势、均线、支撑压力；复权基准锚定最新日线 |
| 新浪分钟线 | 不复权 | 用于当日买卖点与现价比较 |
| TickFlow 分钟线 | 适配器固定的当日价格口径 | 单次计算保持同一来源，并与日线做尺度对齐 |

`TickFlowAdapter` 接受 `none / forward / backward / forward_additive / backward_additive`。
变更复权口径需要复核 `advice/engine.py` 的对齐逻辑；同日收盘比落在 `[0.2, 5.0]` 外时，
对应历史价位不可用于推导交易价格。

### 业绩

同一公司在预告表中可能按多个指标分别列行，不能按最后一行覆盖。`METRIC_PRIORITY`
优先归母净利润，其次使用可识别的利润口径，并把实际指标写入 `metric`。
营收的“略增”不能替代净利润的“续亏”，只有净利润口径参与相关否决。

`direction` 表示同比变化方向，`is_loss` 表示当前是否亏损，`is_profitable_growth` 要求
增长且盈利。业绩变动幅度是百分数，极值可能很大，不能直接乘进分数。

### 五档、逐笔与筹码

- 五档提供当前挂单厚度、委比、价差和挂单墙，不提供撤单率、逐笔委托意图或集合竞价未匹配量。
- 腾讯成交明细从第 0 页开始，包含集合竞价与开盘初段。B/S/M 是行情方推断；
  大单阈值取当日分位，尾盘净额须结合实际数据时点解释。
- 龙虎榜买卖榜可能包含相同整行，须按整行去重；多个“机构专用”可能对应不同机构，
  不能只按席位名称合并。
- 生产链路没有真实筹码分布源。`turnover_cost_15/30` 是成交成本代理，
  `signals/chips.py` 根据 OHLCV 与流通股本估算换手衰减，相关字段带 `_est` 后缀。
  后续接入真实数据应使用独立字段，不能覆盖估算值。
- 北向实时资金流已停止原有披露，历史探针出现接口成功但净买额为零、序列为空的情况；
  本项目不把这些响应当作真实资金流读数。

## 缓存与刷新

| 数据 | 存储与更新方式 |
|---|---|
| 新闻响应 | `NewsCache` 按交易日和来源缓存，受 TTL 约束 |
| 模型新闻分析 | 缓存键包含实际分析输入、提示词与模型配置；分类部分失败不缓存完整结果 |
| 新闻语料 | SQLite 保存正文、来源、首次/最近观察时点与归因，供跨日检索 |
| 静态分类 | 按 schema 与日期读取；兼容旧数组缓存并转换为单个行业；行业与概念共用快照，刷新失败时标注缓存年龄 |
| 个股日线 | `ASHARE_DS_HOME/cache/daily_bars/`，按适配器与复权口径隔离，按交易日合并 |
| 板块与海外指数 | `sector_index/`、`overseas_index/`，保留多年序列，按日期合并 |

个股日线先请求在线数据，成功后更新缓存；网络失败才读取所需区间的缓存。
回退时报告覆盖数量和截止日期，并标明“结果不可视为实时”；没有可用缓存时保留失败。
日线缓存不替代分钟线、盘口或实时快照。

刷新成功、保存成功和已有缓存仍可读分别报告。合并更新使用锁和原子替换，
不要删除仍供进程协调的固定锁文件；完整存储约定见 [状态与归档](ARCHITECTURE.md#状态与归档)。

## 诊断

```bash
ashare-ds tick-health
ashare-ds intraday-check --symbols 600519.SH
ashare-ds intraday-check --symbols 600519.SH --source sina
ashare-ds state
python3 scripts/source_audit.py --repeats 5 --json audit.json
python3 scripts/source_audit.py --only sina_min_1 sina_daily --symbols 000001.SZ --repeats 3 --json audit.json
```

接口探针会联网并消耗配额。`source_audit.py` 记录调用结果、条数、最新数据时点、重复采样成功率
和延迟 p50；单票探针使用 `--symbols` 的首只代码，支持指定名单的批量探针使用归一化后的完整列表。

`--only` 只初始化选中探针需要的依赖。未知探针、所选依赖不可用、没有可用探针或无效参数
退出 2，已有报告保持不变。`--repeats` 至少为 1，显式 `--only` / `--symbols` 必须提供值。
JSON 报告自动创建父目录并原子保存。

脚本的 TickFlow 探针固定使用免费客户端，付费接口探针用于验证权限边界；
检查主流程实际分钟线应使用 `intraday-check`。脚本按工作日近似判断交易时段，不加载节假日表。

盘中时效查看 `median_lag_minutes` 和 `advanced_within_gap`，后者表示两次采样间时间戳是否推进，
默认间隔 90 秒。非交易时段的自然时间差不代表盘中延迟，有限次采样也不能证明全天稳定。
持续轮询是否触发上游限流，需要在实际部署环境验证。

## 历史测量与接口限制

以下保留会影响接入决策的测量，省略逐轮修复过程。成功率只覆盖当次样本，不能外推。

### 舆情（2026-09-13）

证监会旧栏目 `c100028/common_list.shtml` 仍返回 HTTP 200，但内容停留在 2021 年。
当前栏目使用动态列表，已改接官网公开的
`searchList/a1a078ee0bc54721ab6b148884c784a8` JSON 接口，读取标题、原文链接与完整发布时间。
当次返回 20 条，最新为 2026-09-11 18:03:38；以 9 月 13 日 22:00 的 72 小时窗口计，
2 条可用于当期舆情。`official_v2` 缓存键隔离旧栏目响应。

海外官方 RSS 当次仍为 4/5 可达，BLS 返回访问错误；单源采到的 83 条中仅 5 条在去重和
72 小时时效过滤后保留。因此来源健康需要同时看最新发布时间与有效条数，不能只看 HTTP
状态或原始数量。周末无新发布与栏目停更应分开诊断。

### 免费接口（2026-08-01 至 08-09）

| 数据 | 当次记录 |
|---|---|
| TickFlow 分类、成分股、日线 | 默认各重复 5 次全部成功，p50 分别约 0.28s、0.53s、0.25s |
| 新浪分钟线 | 当次返回最近交易日 1970 根，5 次全部成功，p50 约 1.0s |
| 新浪全市场五档 | 当次 5599 只，p50 约 443ms；440 次连续调用未失败 |
| 新浪全市场扫描 | 当次 5529 只，约 5.3s，含 PE/PB、换手和流通市值 |
| 国内官方栏目 | 2026-08-09 三路可达；旧 gov.cn 栏目返回 200 跳转壳，已改用政策主页 |
| 海外官方 RSS | 同日 4/5 可达，BLS 返回 403；BEA 的 PCE 数据不等同于 CPI，非农仍依赖其他快讯旁证 |
| 腾讯逐笔 | 2026-08-03 从第 0 页取数后，消除开盘段缺口；遗漏第 0 页曾少计全天成交额的 4%–24% |

免费 TickFlow 曾在滚动 60 秒的第 61 次请求返回 429。当前客户端默认限制在 55 次/60 秒，
并在限流后按服务端等待时长退避。限流包裹 SDK client，覆盖行情与元数据请求。
表中的 TickFlow 分类、成分股是历史接口测量，当前分类链路已不使用。

### TickFlow Pro（2026-08-02）

当时套餐记录为 ¥99/月；免费与付费分别使用 `free-api.tickflow.org` 和 `api.tickflow.org`。

| 能力 | 当次记录 |
|---|---|
| 全 A 报价 | 5534 只，约 0.7s |
| 标的元数据 | 5534 只，约 0.97s，真实涨跌停价覆盖完整 |
| 单票分钟线 | 可用；历史回溯到 2025-05-23 |
| 分钟线批量与财务 | 当时 Pro 账号无 `klines.intraday_batch` 和 `financials.*` 权限 |
| WebSocket | 未接入生产链路 |

单次分钟线历史返回最多 5000 根，更早数据需逐段前推 `end_time`。当前分钟线适配器取近期单批，
没有提供分钟历史回填或分钟级策略回测。TickFlow 与新浪重叠分钟线存在约 0.15%–0.31% 的最大相对差异，
不要混入同一次计算，也不要将一条来源的历史直接作为另一条来源的规则验证。

`strong_count` 仍使用涨幅 ≥9.5% 的近似，未改为真实涨停判据；修改时需同步校准板块阈值和历史可比性。

### 网络与字段布局

2026-08 的部署出口对不同东财主机表现不同：

| 主机 | 当时结果与影响 |
|---|---|
| `push2.eastmoney.com`、`push2his.eastmoney.com` | 经常连接重置，实时资金流、日线与分钟线不可作为该环境的稳定依赖 |
| `push2ex.eastmoney.com` | 涨停/炸板池可达；不能据此推断其他逐笔接口可用 |
| `datacenter-web.eastmoney.com` | 龙虎榜、席位与业绩接口可达 |

2026-08-04 重试中，个股资金流直到第 6 次才成功一次，排名与东财分钟线仍全部失败。
需要区分出口网络、账号权限与空数据，不能仅凭一次成功调整主链路来源。

2026-08-20 海外快照检查确认，同一新浪请求可取指数、行业/主题 ETF、商品期货、韩国指数和汇率。
各前缀的前收字段不同，由 `adapters/global_market.py` 分别解析：

| 前缀 | 现价 | 前收 | 时间 |
|---|---|---|---|
| `gb_` 美股指数/ETF | `[1]` | `[26]` | `[3]`；`[25]` 是收盘时间戳 |
| `b_` 韩国指数 | `[1]` | `[9]` | 日期 `[6]`、时间 `[5]`；`[8]` 是开盘 |
| `hf_` 期货 | `[0]` | `[7]` | 日期 `[12]`、时间 `[6]` |
| `fx_` 汇率 | `[1]` | `[2]` | 日期 `[17]`、时间 `[0]` |

新增来源或修改解析时，应使用实际响应夹具检查字段关系和时点，避免测试只是复述解析器的假设。
